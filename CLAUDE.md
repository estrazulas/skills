# Skills Repo — Instruções

## Estrutura

```
skills/
├── texto/          # Processamento de texto
├── dev/            # Desenvolvimento e segurança
├── midia/          # Processamento de mídia e documentos
├── comunicacao/    # Comunicação e integração (Discord, etc)
├── headroom/       # Skills do projeto Headroom
├── produtividade/  # Gestão de tarefas
├── util/           # Utilitários diversos
├── requisitos/     # Engenharia de requisitos
├── ifsc_util/      # Skills institucionais IFSC
└── mattpocock/     # Coleção externa (30 skills)
```

## Workflow

1. Criar/modificar skill em `skills/<categoria>/<skill>/SKILL.md`
2. Cada agente tem seu próprio mecanismo para descobrir skills
3. Consulte a documentação do agente que você está usando
